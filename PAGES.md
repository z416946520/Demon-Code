# Demon Code — GitHub Pages

Static landing page for [Demon Code](https://github.com/z416946520/Demon-Code).

## Enable Pages

1. Repository → **Settings → Pages**.
2. **Build and deployment → Source**: `Deploy from a branch`.
3. **Branch**: `main`, **Folder**: `/ (root)`.
4. Save. The site will be published at:

   `https://z416946520.github.io/Demon-Code/`

No build step is required. Open `index.html` directly or serve the directory with any static server.

## Structure

```text
index.html       landing page
styles.css       design tokens and layout
app.js           nav, reveal, copy, terminal, FAQ
404.html         not-found page
assets/          icon and screenshots
.nojekyll        disable Jekyll processing
```
